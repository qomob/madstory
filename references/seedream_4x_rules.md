# Seedream 4.0-5.0 Pro 提示词工程规范 (Layer 1 — 按需加载)

> 本文件包含 Seedream 5.0 Pro / 5.0 lite / 4.5 / 4.0 的提示词方法论，补充 Seedance 2.0 规范中未覆盖的文生图、图像编辑、参考图生图、多图输入/输出等能力。
> **加载条件**: 用户使用 Seedream 4.x/5.x/5.0 Pro 平台，或涉及文生图、图像编辑、参考图生成、多图操作、知识可视化等场景时加载。

## 1. 通用规则 (General Rules)

### 1.1 自然语言清晰描述
用**简洁连贯**的自然语言写明 **主体 + 行为 + 环境**，对美学有要求时补充 **风格、色彩、光影、构图**。

| 推荐 | 避免 |
|------|------|
| 一个穿着华丽服装的女孩，撑着遮阳伞走在林荫道上，莫奈油画风格 | 一个女孩，撑伞，林荫街道，油画般的细腻笔触 |

### 1.2 明确应用场景
有明确应用场景时，在提示中写明图像用途和类型。

| 推荐 | 避免 |
|------|------|
| 设计一个游戏公司的 logo，主体是一只在用游戏手柄打游戏的狗，logo 上写有公司名 "PITBULL" | 一张抽象图片，狗拿着游戏手柄，狗狗上写 PITBULL |

### 1.3 风格渲染
有明确风格需求时，使用精准的**风格词**或提供**参考图像**。

### 1.4 文字渲染
将要生成的**文字内容**放在**双引号**中。

| 推荐 | 避免 |
|------|------|
| 生成一张海报，标题为 "Seedream 4.5" | 生成一张海报，标题为 Seedream 4.5 |

### 1.5 图像编辑目标明确
使用**简洁明确的指令**，说明需要修改/参考的对象及具体操作，避免指代模糊的代词；希望保持不变的部分需强调。

| 推荐 | 避免 |
|------|------|
| 让图中最高的那只熊猫穿上粉色的京剧服饰并戴上头饰，并保持动作不变 | 让它穿上粉色衣服 |

## 2. 文生图 (Text-to-Image)

### 2.1 核心原则
Seedream 5.0 lite / 4.5 / 4.0 对文本理解能力更强，**简洁精确的提示通常优于重复堆叠华丽复杂的词汇**。画面不再泛白。

### 2.2 高密度细节描述
对于细节丰富的图像，通过详细的文本描述精准控制画面细节。每个元素逐一描述其位置、状态、内容。

**示例结构**:
```
[场景概述]。[元素1位置]: [元素1描述]；[元素2位置]: [元素2描述]；... 背景是[背景描述]。[光影描述]。
```

### 2.3 知识可视化
可将知识与推理结果转化为高密度图像内容（公式、图表、教学插图等）。

**关键要求**:
- 使用**专业术语**确保知识点表达准确
- 写清对生成图像的具体要求（可视化形式、版式、风格）

**示例**:
- 在黑板上画出二元一次方程组及其相应的解法步骤
- 绘制一张信息图，展示通货膨胀的成因，每条成因独立呈现，并配有简洁图标

## 3. 图像编辑 (Image Editing)

### 3.1 四种编辑操作

| 操作 | 指令要点 | 示例 |
|------|---------|------|
| **增加** | 明确指出增加的对象和位置 | 给图中女生增加相同款式的银色耳线和项链 |
| **删除** | 明确指出删除的对象 | 去掉女生的帽子 |
| **替换** | 指明替换对象 + 替换为 + 保持不变的部分 | 把最大的面包人换成牛角包形象，保持动作和表情不变 |
| **修改** | 指明修改对象 + 修改属性 + 保持不变的部分 | 让图中三个机器人变成透明水晶材质，颜色从左到右分别变成红黄绿 |

### 3.2 视觉信号控制
当画面复杂难以通过文本准确描述编辑对象时，可采用以下视觉信号：

| 信号类型 | 用法 | 示例 |
|---------|------|------|
| **涂鸦** | 用颜色涂抹标记位置，在 prompt 中指明颜色对应的操作 | 将房间内红色涂抹位置放入电视，蓝色涂抹位置放入沙发，不改变其他布局 |
| **线框** | 用线框标记区域和大小，在 prompt 中指明线框对应的操作 | 放大图中的标题至红框大小，并改成和萨克斯图案一样的颜色和字体风格 |
| **箭头** | 用箭头指示方向和目标 | — |

## 4. 参考图生图 (Reference-to-Image)

### 4.1 四种参考类型

| 参考类型 | 提取信息 | 提示词结构 |
|---------|---------|-----------|
| **参考人物形象** | 角色外貌特征 | 参考图中的人物形象 + [生成画面描述] |
| **参考风格** | 艺术风格/视觉语言 | 参考图的[风格描述] + [生成内容描述] |
| **参考虚拟实体形象** | 3D/IP/虚拟角色 | 图中的形象变成[目标材质/形态] + [场景描述] |
| **参考款式** | 产品设计/服装款式 | 衣服款式与图中一致 + [变化描述] |

### 4.2 提示词双要素
参考图生图的提示词必须包含两部分：
1. **指明参考对象**: 清晰描述希望从参考图中提取并保留的元素
2. **描述生成画面**: 具体说明希望生成的画面内容、场景等细节

### 4.3 设计草图→高保真
从设计草图生成高保真效果图时：
1. 提供清晰的原始图片，若图中有文字说明则注明"遵循图中文字内容进行生成"
2. 明确主体与要求（如高保真 UI 界面、现代简约风格客厅实景图）
3. 明确指出需与参考图保持一致的关键要求（如家具位置与参考图一致）

## 5. 多图输入 (Multi-Image Input)

### 5.1 三种复合操作

| 操作 | 提示词结构 | 示例 |
|------|-----------|------|
| **替换** | 将图一的[元素]替换为图二的[元素] | 将图一的主体替换为图二的主体 |
| **组合** | 让图一[元素]穿上/使用图二的[元素] | 让图一人物穿上图二的服装 |
| **迁移** | 参考图二的风格，对图一进行风格转换 | 参考图的风格，对图一进行风格转换 |

### 5.2 多图引用规范
- 使用"图一/图二/图三"明确指代不同输入图像
- 每张图的参考要素需明确（人物/服装/风格/产品）
- 多图之间需兼容：光源逻辑、造型、质量水平

## 6. 多图输出 (Multi-Image Output)

### 6.1 触发方式
通过以下提示词触发组图生成：
- "一系列"/"一套"/"组图"
- 具体数字表明图片数量

### 6.2 适用场景
| 场景 | 说明 |
|------|------|
| 分镜序列 | 角色连贯、风格统一的分镜图 |
| 漫画创作 | 多格漫画的连续画面 |
| IP 产品 | 统一视觉风格的成套设计 |
| 表情包 | 同一角色的多种表情/动作 |

## 8. 平台适配提示

当 MadStory 检测到用户使用 Seedream 4.x/5.x/5.0 Pro 平台时：
- 自动切换为图片生成模式，移除 Camera/Motion 相关参数
- 应用双引号文字渲染规则
- 启用图像编辑/参考图/多图操作语法
- 知识可视化场景使用专业术语
- 不注入 Negative Prompt（图片模式不需要）
- **5.0 Pro 专属**: 检测到高密度信息/多语种/影视感人像需求时，主动推荐 5.0 Pro 并启用对应增强能力

## 8.5 Seedream 5.0 Pro 专属能力 (Pro-Exclusive Features)

> 以下能力仅适用于 **Seedream 5.0 Pro** 版本。5.0 Lite / 4.5 / 4.0 不支持。使用前需确认用户平台版本。

### 8.5.1 交互式精准编辑 (Interactive Precision Editing)

5.0 Pro 在 4.x 的涂鸦/线框/箭头基础上，新增 **坐标级位置控制**：

| 控制方式 | 用法 | 适用场景 | 示例 |
|---------|------|---------|------|
| **框选 (Bounding Box)** | 框选目标区域，在 prompt 中指明该区域操作 | 局部替换/修改 | 框选左上角区域，将其中的人物服装改为红色丝绒材质 |
| **点位 (Point Marker)** | 标记特定位置点，指定该点的生成内容 | 添加物体 | 在画面中心偏右位置添加一盏复古台灯 |
| **箭头 (Arrow)** | 指示方向和目标 | 运动方向/视线引导 | 箭头从左指向右侧窗户，表示人物应面向窗户 |
| **标注框 (Annotation Box)** | 框选区域并附加文字标注 | 区域内容说明 | 标注框选中背景区域，标注"替换为雨夜城市街道" |
| **坐标 (Coordinates)** | 直接用坐标值指定位置 `[x1,y1,x2,y2]` | 精确定位 | 在 `[0.3,0.2,0.7,0.8]` 区域内生成一个水晶花瓶 |

**与 4.x 编辑的关键区别**: 4.x 的涂鸦/线框是区域模糊控制（"大概这片区域"），5.0 Pro 的坐标/标注框是像素级精确控制（"精确到这个坐标范围"）。

### 8.5.2 高密度信息呈现 (High-Density Information)

5.0 Pro 擅长在单张图像中呈现 **极高密度的结构化信息**，且保持每个元素清晰可辨。

**适用场景**:
- 复杂技术图表（机械剖面图、电路图、建筑平面图）
- 高密度排版（信息图、数据仪表盘、杂志版式）
- 多元素场景（百人群像、超市货架、城市鸟瞰）
- UI 界面（完整 App 界面、仪表盘、多面板布局）

**提示词策略**:
- 使用 **空间定位结构**: "左上角…；右侧…；底部…" 逐区域描述
- 每个元素给出 **具体内容** 而非模糊形容: "左侧第二个货架上放着三罐金枪鱼罐头"
- 复杂排版用 **网格逻辑**: "3×4 网格布局，每格包含一个图标和对应文字说明"
- 利用 5.0 Pro 的 **CoT 空间推理**: 模型会先规划布局再渲染，因此可以描述元素间的空间关系（"A 在 B 的正上方，C 与 B 等高但在右侧"）

### 8.5.3 原生多语种文字渲染 (Native Multilingual Text)

5.0 Pro 支持在图像中渲染 **中文、英文、日文、韩文** 等多语种文字，且保持字形准确。

**提示词规则**:
- 所有语种文字均使用 **双引号** 包裹: `"文字内容"`
- 多语种混排时分别标注: 标题 `"Seedream 5.0"` 副标题 `"新世代生图引擎"`
- 日文/韩文可直接使用原文: 竖排标题 `"人工知能の未来"`
- **与 4.x 的区别**: 4.x 仅支持中英文且英文偶有拼写错误；5.0 Pro 多语种准确率接近 100%

### 8.5.4 影视感增强 (Cinematic Enhancement)

5.0 Pro 在画面质感上大幅提升，接近专业电影摄影输出。

**自动增强维度（无需在 prompt 中显式请求）**:
- **对比度与动态范围**: 自动应用电影级高动态范围，暗部有细节、亮部不过曝
- **景深控制**: 人像/特写自动生成自然浅景深，背景虚化有层次
- **光影层次**: 复杂光源（混合自然光+人造光）的交互渲染更真实
- **胶片质感**: 微妙的颗粒感和色彩分离度，减少"AI 过渡光滑"的塑料感

**主动利用策略（在 prompt 中激活）**:
- 人像模式: 添加 `cinematic portrait, shallow depth of field, natural skin texture`
- 场景模式: 添加 `cinematic lighting, volumetric light, atmospheric haze`
- 色彩模式: 添加 `teal and orange color grade, film look, anamorphic lens flare`

### 8.5.5 人像质感提升 (Portrait Quality Enhancement)

5.0 Pro 的人像输出达到专业商业摄影水准。

**增强维度**:
- **皮肤纹理**: 毛孔级细节，保留自然肤质而非过度磨皮
- **发丝细节**: 单根发丝可辨，发际线自然，无"头盔发"问题
- **眼神光**: 瞳孔中自动生成自然眼神光反射，让人物"有神"
- **微表情**: 嘴角、眉眼的微妙表情更精准

**提示词建议**:
- 添加 `professional portrait photography, natural skin texture, detailed eyes`
- 指定布光: `Rembrandt lighting` / `butterfly lighting` / `split lighting`
- 指定镜头: `85mm f/1.4 portrait lens` / `shot on Sony A7R V`

### 8.5.6 Visual Chain-of-Thought (CoT) 利用

5.0 Pro 内置 **视觉思维链 (Visual CoT)** — 先推理再渲染。

**如何利用 CoT 获得更好结果**:
- **描述空间关系而非绝对位置**: "书在桌上，杯子在书的右边，杯子比书矮" — CoT 会自动解析相对关系
- **描述因果逻辑**: "因为窗户在左侧，所以右侧墙面有阴影" — CoT 会据此生成一致光影
- **分步描述复杂场景**: "先有一个长桌，桌上从左到右依次是…，桌子对面是两把椅子，椅子后面是…" — CoT 按空间逻辑逐步构建

### 8.5.7 多轮对话式编辑 (Multi-Turn Editing)

5.0 Pro 支持 **多轮对话式** 逐步精修图像，而非一次性生成。

**工作流**:
```
Turn 1: 生成基础图像
Turn 2: "把背景换成夜晚城市" → 保持主体不变，仅改背景
Turn 3: "人物服装改为红色" → 保持背景和姿势不变
Turn 4: "增加景深虚化效果" → 全局风格调整
```

**规则**:
- 每轮编辑明确指出 **保持不变的部分**: "保持人物表情和姿势不变，仅修改…"
- 复杂修改拆分为多轮，每轮只改一个维度（背景/服装/光影/构图）
- 多轮编辑累积不超过 5 轮，之后建议重新生成

### 8.5.8 透明背景输出 (PNG Transparency)

5.0 Pro 支持 **PNG 透明通道** 输出，适用于:
- 产品抠图（电商主图、目录图）
- 角色立绘（游戏/UI/动画）
- Logo 与图标设计
- 素材合成（为后期合成准备独立图层）

**提示词**: `transparent background, PNG with alpha channel, isolated subject`
