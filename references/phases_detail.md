# 分镜推导流程详情 (Layer 1 — 按需加载)

> 本文件包含 Phase 0-7 的完整推导指引。仅在进入对应阶段时加载。

---

## Phase 0: 模式选择与意图澄清 (Perception)
> **Harness 层级**: Read — 通过上下文管理器将用户输入翻译为结构化意图
- 确认创作目标（电影概念 / 卖货 / 种草 / 品牌 / 叙事 / 艺术实验）
- 选择对应 Mode（含 Mode 0 创意探索），明确核心约束
- 确定输入素材类型（纯文本 / 产品图 / 参考图 / 参考视频）
- **时长充分性检查**: 15s 是 AI 模型的技术限制，不是创意选择。评估用户的故事意图是否能在 15s 内完成：
  - **适合 ≤15s 的内容**: 产品展示、单一情绪片段、视觉冲击、社交媒体素材、一镜到底空间展示
  - **不适合 ≤15s 的内容**: 对话场景（需要来回切换）、情绪积累（需要铺垫时间）、角色建立（需要多个行为展示）、复杂叙事弧线
  - **当内容不适合 15s 时**: 主动建议拆分为多段生成 + 后期剪辑，并告知用户每段的核心内容边界。不要被动接受 15s 然后产出拥挤的方案
- **产出**: Mode 确认 + 输入策略 + 创作意图结构化描述 + 时长规划（单段 15s 或多段拆分方案）

## Phase 1: 核心创意锁定 (Core Concept) (Planning)
> **Harness 层级**: Eval — 调用拦截器捕获创意意图并路由到正确的模式引擎
- 明确主体（产品 / 人物 / 场景）
- 定义单镜头内唯一的动作或信息点
- 确定情感基调和观众预期反应
- **拒绝策略**: 如果用户在一个镜头里塞了 > 1 个动作或 > 1 个信息点，主动建议拆分
- **产出**: Subject + Action 描述

## Phase 2: 时间轴与节奏 (Timeline & Rhythm) (Action)
> **Harness 层级**: 执行器 — 将时间规划注入确定性时间线模型
- 规划时长内的时间分配（默认 15s，电影模式支持 30-180s）
- 定义关键帧节点（至少 3 个：入场 / 核心 / 收尾）
- 多镜头模式：规划 Cut-to 节点和镜头间节奏关系
- **剪辑节奏决策** `[导演参考]`: 根据叙事意图选择剪辑策略（参考 `assets/cheat_sheet.json` → `editing_techniques`）。这些策略在分镜规划阶段标注，实际在后期剪辑中由用户执行：
  - **L-Cut**（声音先于画面切）：对话节奏、情绪延续、回忆转场
  - **J-Cut**（画面先于声音切）：悬念预告、进入新场景、时间跳跃
  - **Jump Cut**：时间压缩、焦虑感、UGC 快节奏
  - **Match Cut**：形状/颜色/动作衔接、跨时空转场
  - **Smash Cut**：惊吓转场、梦境惊醒、反差冲击
  - **Montage**：时间流逝、训练过程、事件累积
- **景别递进策略** `[导演参考]`: 何时从全景递进到特写（情绪积累），何时反向（揭示环境）。避免景别跳跃超过 2 级（如全景直接切大特写会令观众迷失）
- **180度线规则** `[导演参考]`（多镜头对话场景）：所有机位保持在对话轴线的同一侧，违反会导致观众空间感反转。AI 模型不感知轴线，此规则供分镜规划参考
- **产出**: Timeline 描述 + 关键帧定义 + 剪辑策略标注

## Phase 3: 视觉构图 (Visual Composition) (Action)
> **Harness 层级**: 执行器 — 构图参数化输出
- 确定画面比例、构图方式
- 主体在画面中的占比和位置
- 角色 / 产品与环境的空间关系
- **电商提醒**: 产品必须占画面显著位置，不要放在边角
- **UGC 提醒**: 保持自然取景，不要过度设计构图
- **电影提醒**: 遵循三分法/黄金分割/对称构图等经典电影语言
- **产出**: Composition 描述 + 画幅建议

## Phase 3.5: 表演与调度 (Performance & Blocking)
> **Harness 层级**: Eval — 拦截"物体摆放"思维，强制将角色作为表演者处理
>
> **AI 可执行性声明**: 本 Phase 内容分为两类——
> - `[模型可执行]` = 可转化为提示词描述，AI 模型有一定概率正确渲染
> - `[导演参考]` = 无法通过当前 AI 模型实现，仅供创作决策和后期剪辑参考

- `[模型可执行]` **走位 (Blocking)**: 用具体动作描述角色空间位置（如"角色从画面左侧缓步走向右侧窗户"）。AI 模型能渲染位移，但理解不了"靠近=亲密"这类符号逻辑——叙事含义靠用户在剪辑中赋予
- `[导演参考]` **视线匹配 (Eyeline)**: 对话场景中角色视线方向应与对手匹配。当前 AI 模型在单镜头内能生成视线方向，但跨生成调用间无法保持一致性。此规则用于多镜头规划，实际生成后需人工检查
- `[导演参考]` **反应镜头策略**: 何时切入反应镜头是剪辑决策，不是单镜头生成决策。在分镜规划阶段标注反应镜头位置，实际在后期剪辑中执行
- `[模型可执行]` **潜台词表演 (Subtext)**: 通过具体微表情描述暗示内心状态（如"嘴角微微上扬但眼神冰冷"）。AI 模型能渲染复合表情描述，但精度有限
- **电商提醒**: 产品是"主角"，运动路径围绕产品展开，角色手部动作引导观众视线到产品
- **UGC 提醒**: 保持自然肢体语言，避免"表演感"——真实创作者的身体松弛度是可信度的核心
- **电影提醒**: 每个走位选择都是叙事决策。参考 `assets/cheat_sheet.json` 中 `cinematic_camera_language.composition_rules` 的空间关系
- **短剧提醒**: 标志性动作（角色档案中的 habits）必须在本 Phase 显式安排出现时机
- **产出**: Performance Notes（走位路径 + 视线方向 + 反应镜头规划 + 潜台词标注 + 每项标注 `[模型可执行]`/`[导演参考]`）

## Phase 4: 镜头运动 (Camera Movement) (Action)
> **Harness 层级**: 调用拦截器 — 捕获镜头运动意图并路由到运动强度参数
- 选择 1 个主导镜头运动（不可在一个镜头内混用多种运动）
- 在 Timeline 上标注运动变化
- 给出 Motion Strength 建议值
- **原则**: 每个镜头运动必须能用一句话说明其叙事理由（如"推近→揭示角色内心紧张"）。如果理由只是"看起来酷"，改为 static
- **产出**: Camera 描述（含运动强度）+ Motion Strength 参数

## Phase 5: 光影与质感 (Lighting & Texture) (Action)
> **Harness 层级**: 执行器 — 光影参数化输出
- 光源方向、色温、对比度
- 环境细节（烟雾、颗粒、反射、材质）
- 整体色调和视觉风格
- **电商提醒**: 光源不要遮挡产品标签
- **UGC 提醒**: 自然光优先，避免棚拍感
- **电影提醒**: 每个光源有情绪动机，参考 `assets/cheat_sheet.json` 中的 `cinematic_lighting_extended`
- **产出**: Lighting 描述 + 风格预设

## Phase 6: 声音设计 (Sound Design) (Action)
> **Harness 层级**: 执行器 — 声音参数化输出
- **声音来源分类（第一决策）** `[导演参考]`: 在选择具体音效之前，先决定声音的叙事层级。当前 AI 视频模型（Seedance 2.0）基本不生成音频，此分类供后期声音设计参考：
  - **Diegetic（画内音）**: 角色和场景中能听到的声音——收音机播放的音乐、街道车流、角色哼的歌、雨打窗户。建立场景真实感
  - **Non-Diegetic（画外音）**: 只有观众听到的声音——配乐、旁白、音效强调。控制观众情绪
  - **Trans-diegetic（过渡）**: 从画内音变为画外音（如角色打开收音机→音乐渐变为配乐），用于场景转换或情绪升级
- 确定音效类型（环境音 / 音效 / 对白 / 音乐）
- 音乐风格和节奏（参考 `assets/cheat_sheet.json` 中的 `sound_design_presets`）
- 音画同步点（关键动作匹配音效）
- **电商提醒**: 音乐不分散注意力，让产品说话
- **UGC 提醒**: BGM 保持在语音之下
- **电影提醒**: 参考导演声音签名（如 Nolan 的低频冲击）；静默也是一种选择——关键情绪转折点可以让声音突然消失
- **产出**: Sound Design 建议（含 diegetic/non-diegetic 标注）

## Phase 7: 最终合成与参数输出 (Export) (Feedback)
- 整合所有 Phase 产出为完整提示词
- 生成 Negative Prompt（基于 Mode 自动注入）
- **历史缺陷增强**: 检查当前 Mode 的 DEFECT_LOG，如果有高频缺陷记录：
  1. 在 NEGATIVE_PROMPT 追加针对性保护词（如 UGC 模式历史记录显示 7s 后 face drift 高频 → 追加 `no late-stage face drift`）
  2. 在输出中增加 `KNOWN_RISKS` 字段，列出该 Mode 最可能出现的缺陷及用户需重点检查的时间段
- 输出多模态建议（参考图 / 参考视频 / 音频建议）
- 输出平台适配参数（根据目标平台约束自动适配）
- 质量自检：对照质量门禁逐项检查
- **降级策略**:
  - 结构不完整 → 回退到上一 Phase 补充
  - 参数超范围 → 自动 clamp 到安全区间
  - 模式不匹配 → 提示用户确认或自动切换兼容模式
- **产出**: 完整分镜方案（含 KNOWN_RISKS + DEFECT_LOG 模板供用户返回后填写）
