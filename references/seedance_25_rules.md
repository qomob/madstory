# 即梦 Seedance 2.5 提示词工程规范（默认基准）

> 本文件为 Seedance 2.5 完整规则。**2.5 为默认基准**；积分成本敏感或需降级时使用 Seedance 2.0，规则见 `seedance_v2_rules.md`。2.0 与 2.5 的提示词在主体结构上兼容，但 2.5 新增时间戳/编辑/白模/多语种/多人/绿幕等能力，且参数上限全面放宽。

## 0. 版本选择决策

| 场景 | 选择 | 理由 |
|------|------|------|
| 默认创作 / 长视频(>15s) / 时间戳精准导戏 / 局部编辑 / 白模预演 / 多语种出海 / 多人同框 / 绿幕合成 | **Seedance 2.5** | 2.5 全面升级 2.0，所有 2.0 能力 2.5 均支持且更优 |
| 积分受限 / 简单产品展示(≤15s) / 成本敏感批量生成 / 短参考素材(总≤15s) | Seedance 2.0 | 2.0 积分消耗约为 2.5 的 1/3，短素材场景性价比更高 |

> 2.0 不支持：仅传音频、>15s 参考素材、超长视频、时间戳帧级控制、局部编辑、白模、绿幕、BGM 分离。需这些能力必须用 2.5。

## 1. 参数规格

### 1.1 输入素材限制（2.5 vs 2.0）

| 类型 | 2.5 数量 | 2.5 单个时长 | 2.5 总时长 | 2.0（对比） | 格式 |
|------|---------|-------------|-----------|------------|------|
| 图片 | ≤30 张 | - | - | ≤9 张 | jpeg/png/webp/bmp/tiff/gif/heic/heif |
| 视频 | ≤10 段 | [2, 30] s | ≤30 s | ≤3 段，总≤15s | mp4/mov |
| 音频 | ≤10 段 | [2, 30] s | ≤30 s | ≤3 段，总≤15s | wav/mp3 |

**图片**：宽高比 (0.4, 2.5)，宽高长度 (300, 6000) px，单张 < 30 MB，请求体 ≤ 64 MB（大文件勿用 Base64）
**视频**：分辨率 480p-4k，宽高比 [0.4, 2.5]，宽高长度 [300, 6000] px，总像素 [409600, 8295044]，单视频 < 200 MB，帧率 [24, 60]
**音频**：单个 < 15 MB，请求体 ≤ 64 MB
**多模态限制**：2.5 支持仅传音频；2.0（R2V 链路）不支持仅传音频，必须至少传图/视频

### 1.2 输入素材建议（稳定性经验值）

| 场景 | 建议值 | 稳定性下降区 |
|------|--------|------------|
| 主体音视频 数量 | 1-5 主体效果好 | 6-10 主体需抽卡 |
| 主体音视频 时长 | 5-10s 效果好 | 更长需抽卡 |
| 主体图 数量 | 1-8 主体效果好 | 9-12 主体需抽卡 |
| 多视角主体图 | ≤5 主体：单/多视图均可 | >5 主体：单视图更稳（多图多视图 > 单图多视图） |
| 视频编辑 输入时长 | ≤20s 效果好 | 更长需抽卡 |
| 视频参考图编辑 数量 | 1-5 张效果好 | 6-8 张需抽卡 |

### 1.3 生成参数

- **duration**：`-1` & `[4, 30]`，即 97 - 721 帧（2.0 为 97 - 361 帧）
- **输出分辨率**：480p / 720p
- **超长视频模式**：单次直出 30 - 180 s
- **视频延长**：原视频 ≤ 30 s 才可延长；单次延长 4 - 30 s；套娃式最长 60 s

### 1.4 功能交互模式（即梦界面 4 选 1）

| 模式 | 用途 | 备注 |
|------|------|------|
| 全能参考 | 默认，多模态参考生成（对应 2.0 的多模态参考） | - |
| 智能编辑 | 对已生成/本地上传视频做局部元素修改（文字描述） | 2.5 新增 |
| 超长视频 | 30 - 180 s 单次直出 | 2.5 新增 |
| 首尾帧 | 首帧/尾帧锁定生成 | 沿用 2.0 |

## 2. 提示词公式

### 2.1 基础 4 段式（主公式）

```
完整提示词 = 【素材描述】+【一句话概述】+【具体情节描述】+【全局补充（结尾）】
```

| 段落 | 回答 | 要点 |
|------|------|------|
| 素质描述 | 哪个素材是什么？ | 素材编号(按上传顺序) + 具体用途(人物/音色/动作/场景)。无素材可省略 |
| 一句话概述 | 整体拍什么？ | 主体 + 地点 + 事件 + 题材/风格 + 特殊运镜 |
| 具体情节描述 | 每段发生什么？ | 分时间轴/故事线。每段含 ➕正向(画面+运镜+动作+台词+音效) + ➖反向(不要的元素) |
| 全局补充（结尾） | 贯穿始终的约束 | 机位 + 环境/场景特征 + 整体声音/氛围 + 光影；全局禁止项(字幕/bgm/崩坏点)再次强调 |

### 2.2 真人人物 7 维公式

```
人物 = [年龄/种族] + [肤色/皮肤质感] + [面部细节特征] + [眼神/灵魂] + [发型/发色] + [服装/服装质感] + [体型/情绪/气质] + [其他要求]
```

动画人物也可套用此公式。每维细分公式：

- **[年龄/种族]**：[具体岁数] + [国籍/人种] + [风格形容词] + [脸型名词]
  - 例：22 岁东亚女性，清冷古典的骨相脸
- **[肤色/皮肤质感]**：[冷暖色调] + [具体肤色] + [质感形容词] + **强制保真后缀：保留真实的微细毛孔与肌肤纹理**
  - 例：冷调白皙肤色，透出细腻的温润质感，保留真实的微细毛孔与肌肤纹理
- **[面部细节特征]**：[眼型] + [眉骨] + [鼻梁] + [唇形] + [下颌线]（至少 3-4 点组合）
- **[眼神/灵魂]**：[眼神形容词] + [目光传达的信息/比喻] + [底层情绪]
- **[发型/发色]**：[发色] + [状态/质感] + [发型名词] + [环境互动(被风吹/凌乱)]
- **[服装/服装质感]**：[版型/剪裁] + [颜色] + [服装名词] + [布料材质/新旧状态] + [穿着方式/细节]
- **[体型/情绪/气质]**：[骨架/肩部特征] + [构图/镜头要求] + [动作/视线] + [整体氛围词]

> 关键：**"保留真实的微细毛孔与肌肤纹理"** 是去 AI 感、避免塑料皮肤的核心保真后缀，每个真人都应带。

### 2.3 30 秒长视频 3 模块公式

```
总述名称：一句话描述整个视频基调
模块一：【多模态参考层】
模块二：【全局设定】
模块三：【时间戳剧本分镜】
```

- **模块一（多模态参考层）**：`基于上传的[参考素材类型]，严格保持@图1的[面孔/特征]一致性，保持@图2的[构图/白模/空间关系]一致，严格锁定人物站位`。全文可多次 @图/@视频/@音频 增强准确性
- **模块二（全局设定 = 全局世界观 + 防崩坏）**：`[基础环境与质感] + [视觉风格] + [镜头语言] + [人物造型] + [表演核心] + [禁止项]`
  - 禁止项从 [声音] + [字幕] + [行为] + [容易崩坏的地方] 多方入手
- **模块三（时间戳剧本分镜）**：见 §3

### 2.4 超长视频公式（30 - 180 s）

```
完整提示词 = 【全局参数】+【素材描述】+【一句话概述】+【具体情节描述】+【全局补充】
```

- **全局参数**：因超长视频时间长，在开头再次强调生成时长（几分钟）、画幅比例等
- 其余段落同基础 4 段式，重点是把素材 @ 清楚 + 故事描述清楚

### 2.5 视频延长公式

**一镜到底延长**（自然连贯、动作延续）：
```
参考@视频1的内容，延长视频 Xs [向前/向后]延长。
要求延长自然、动作衔接流畅、动作衔接自然，禁止生硬切镜、禁止物体凭空出现。
[新增段的画面/动作描述]
```

**切镜/转场延长**（有景别/转场切换）：
```
切镜设定 = [转场类型指引] + [基础约束要求] + [切镜逻辑要求]
```
- **转场类型指引**：需要在切镜处使用"XX 转场"转场（禁止生硬切镜、禁止物体凭空出现）
- **基础约束要求**：保持镜头呼吸感与时长协调 + 具体过渡描述
- **切镜逻辑要求**：要求必须自然切换场景（可加景别切换描述，如"景别由特写转变为中景"）
- 也可给几个转场让模型自选：`请从 [自然镜头切换/遮罩转场/水墨转场/相似物转场] 中根据本片风格选择最合适的一种`

> 提示词只对延长部分生效，原视频画面完全保留。套娃式：只要产物 ≤30s 就能再次延长。

### 2.6 智能编辑 / 高级编辑 / 视频编辑公式

**智能编辑**（文字描述修改）：
```
[具体修改对象/什么东西] + [动作与变化描述] + [生效时序]
```
- 必填词：编辑视频里的 xx / 增加 / 删除 / 修改 / 替换 / 改成
- 尽可能写 A → B 的变化
- 例：在视频的 1-8 秒，把男生的牛仔裤，替换为深黑色的西装裤

**高级编辑 / 视频编辑**（圈选标记 + 文字）：
```
[标注工具与方位] + [具体修改对象] + [动作与变化描述] + [生效时序]
```
- **标注工具与方位**（精准定位防误伤）：框/线/箭头/文字/地标点 + 关注内部还是外部
  - 例：红框内 / 沿着红色箭头指向的区域 / 地标点处 / 红线左侧
- 与点击确认后出现的系统时间轴标签（如 `⏱️00:00 视频帧标注`）配合使用
- 生效时序：全片统一修改 / 仅在 X-Ys 期间变化 / 从第 N 秒起逐渐显现

### 2.7 白模公式

**粗颗粒度**（简单几何体，提供动态骨架，从零生成全新视频）：
```
【参考声明】+【对应关系映射】+【剧情详述】+【场景处理】+【整体收束】
```
- **参考声明**：参考[视频1]的 {运镜|动作|动线|光影变化|角色站位|音乐音效|画面节奏}
- **对应关系映射**：将[视频1]中的 {颜色/形状特征} 模型替换为[图X]的 {角色名}
- **补充**：粗颗粒度若有四肢/翅膀，需写出完整动作序列避免僵化。**最佳实践：不上传有四肢/翅膀类的模型**

**细颗粒度**（建模完整，材质/光影/风格替换）：
```
【渲染指令】+【分段渲染描述】+【场景处理】+【整体收束】
```
- **渲染指令**：将[视频1]的白模动画渲染成最终成片
- **分段渲染描述**：`0-{N}s：{渲染要求——背景环境、色调氛围、人物材质、光影效果} {N}s {转场触发点与方式}：{转场后新场景渲染描述}`
- **补充**：上传参考视频需去除 {轨迹线|坐标线|相机 cone} 等干扰信息

### 2.8 5 层结构元素检查清单（降级为校验）

> 原 5 层结构（Subject→Action→Camera→Style→Constraints）不再作为输出主结构，降级为每个分镜的元素完整性校验。输出主结构使用 4 段式。

- [ ] **Subject**：主体明确且可识别？
- [ ] **Single Action**：单一动作/信息点（一个镜头 ≤ 1 个主导运动）？
- [ ] **Camera Move**：镜头运动 ≤ 1 个主导方式？
- [ ] **Style & Lighting**：风格光影明确？
- [ ] **Constraints**：禁止项已声明？

## 3. 时间戳文本控制

2.5 原生支持基于时间戳的剧情与镜头区间控制，精确到秒级（甚至帧级）。

### 3.1 语法

- 秒级：`[开始秒 - 结束秒]` 或 `[00.0 - 05.0s]`
- 帧级：`第 N 帧`（如 24fps 下 240 帧 = 10s）
- 在描述的镜头画面/对白/动作前加时间戳区间标记，按时间顺序编写剧本

### 3.2 每段时间切片公式

```
[开始秒 - 结束秒] + [核心阶段/主题]
  • [动作/表情 等物理层面指令]：[景别] + [构图] + [人物细节动作]
  • [情感解析或镜头调度 等维度的潜台词]：向 AI 解释物理指令的深层表达
```

### 3.3 适用场景

- 多镜头剧情短片：每个镜头停留时长足够，避免剧情"快进"
- 卡点视频 / 音乐 MV：视觉动作卡点音乐情绪变化
- 广告展示 / 课程演示：分阶段展示产品细节（前 5s 外观 → 中间 10s 功能 → 最后 5s 效果）

## 4. 多模态参考（Omni-Modal Reference）

### 4.1 50 素材投喂

- 30 图 + 10 视频 + 10 音频，一次性全喂
- 角色形象（正面/3-4 侧/表情表）→ 图；场景调性 → 图；运镜节奏 → 视频；配乐情绪 → 音频
- 从"写提示词"升级为"参考式创作"，对不擅长写长 prompt 的新手友好

### 4.2 @ 标签绑定

- `@图片1` / `@视频1` / `@音频1` 绑定到具体 beat
- 全文可多次 @ 引用，增强准确性
- 例：`@图片1 close-up，@图片2 wide`

### 4.3 音色参考

```
上传目标音色音频（建议清晰无杂音人声）+ 输入文案 + "参考@音频1说XX，并保持[低沉悬疑的语调]"
```
- 高保真音色复刻 + 深层情感与细节复刻
- 适用：微短剧强情绪演绎、品牌专属声

### 4.4 多人参考

- 解决多人场景"双胞胎（长相趋同）"与"换脸错位"问题
- 每个角色独立面部轮廓、五官、专属气质、专属穿搭
- 提示词明确各角色动作与关系：`人物 A 与人物 B 正坐在篝火旁交谈，人物 A 递给人物 B 一杯水`

### 4.5 多语种

- 支持：中文、英语、西班牙语、印尼语、马来语、泰语、阿拉伯语、葡萄牙语、越南语、日语、韩语
- 直接用母语写 prompt 和台词；口型与字幕逐语言精准对齐
- 强制语言输出：`最终成片中的所有文字必须全部为[韩文]，禁止出现中文、英文或其他语言`
- 适用：出海营销/本土化广告、多语言短片

> 无缝转场核心：保持两段原视频不被修改，模型在间隙生成过渡画面。可借助动作触发、视线牵引、遮挡转场等手法。

## 6. 转场类型表（视频延长 / 切镜用）

### 6.1 基础转场

| 转场 | 说明 | 适用场景 |
|------|------|---------|
| 自然镜头切换 | 类似硬切但强调呼吸感、留足切换时间，不生硬 | 绝大多数常规叙事 |
| 淡入淡出 | 画面从全黑/全白浮现或慢慢暗下 | 开头结尾 / 时间流逝 / 剧情彻底结束 |
| 叠化 | A 变透明同时 B 浮现，1-2s 柔和重叠 | 回忆 / 梦境 / 抒情过渡 |
| 白闪 / 黑闪 | 瞬间闪白/黑后极速切入下个画面 | 卡点 / 混剪 / 紧张刺激 |
| 擦除 | B 像推拉门从某方向推走 A | 复古风格 / 明显地点转移 |

### 6.2 创意转场

| 转场 | 说明 | 适用场景 |
|------|------|---------|
| 遮罩转场 | 物体（墙/背影/手掌/柱子）遮挡全屏变黑后拉开新场景 | 空间跨越（穿镜、穿纸） |
| 相似物转场 | A 末帧与 B 首帧形状/轮廓/颜色相似 | 蒙太奇（圆月→咖啡拉花） |
| 动作转场 | 镜头甩动产生模糊，B 顺同向甩入定格 | 动感极强（动作片/跑酷/Vlog） |
| 动态接力转场 | 人物动作衔接（A 跳出画框→B 从画框上方落入） | 换装 / 跨地区旅行拼接 |
| 拉近 / 拉远转场 | 极致放大 A 细节（瞳孔/锁孔）变 B 全貌 | 宏大叙事 / 微观切换（套娃式） |
| 水墨转场 | 浓墨滴入水中晕染扩散，A 随墨迹消失 B 浮现 | 东方美学 / 古风 / 回忆 |

### 6.3 转场通用公式

```
需要在切镜处使用"[转场名]"转场（禁止生硬切镜、禁止物体凭空出现）。
[具体过渡描述：A 画面如何过渡到 B 画面]。
要求必须自然切换场景。（可加：并且景别由[特写]转变为[中景]）
```

## 7. Negative Prompt 升级（禁止项）

2.5 负向响应大幅优化，从 2.0 的 `no xxx` 升级为更明确的"禁止"表述，响应更好。

### 7.1 全局禁止项（放全局补充段）

```
禁止生成字幕、禁止生成 BGM、禁止[容易崩坏点，如：流鼻涕/眼泪提前滴落/夸张哭腔]
```

### 7.2 按场景禁止项（参考 2.0 分类，2.5 下响应更好）

| 场景 | 禁止项 |
|------|--------|
| 电商产品 | logo 变形、包装塌陷、标签模糊、产品复制、瓶盖漂移 |
| UGC | 多余手指、人脸漂移、唇部不匹配、产品消失、画面抖动 |
| 电影感 | 镜头抖动、物体融化、随机文字、浑浊光影、死黑 |
| 多镜头 | 跨镜头角色漂移、场景不一致、转场瑕疵 |
| 短剧 | 跨集角色面部漂移、服装混乱、场景跳跃、配音不匹配、字幕不同步 |

### 7.3 去字幕 BGM 专项

- 直接写：`纯净视频，无字幕，无背景音乐`
- 或：`强制去除字幕与自带 BGM（静音生成）`
- 2.5 有效解决随机字幕和无关 BGM 意外出现的问题

### 7.4 局部编辑保留声明

- 编辑时强调：`保持其他不变`、`人物本人、皮肤、头部、手脚、身体姿态、运动动作保持不变`
- 移除后补全：`原本被遮挡的[地毯/墙面]需要自然补全，不能留下残影或模糊补丁`

## 8. AI 模型限制（2.5 更新）

| 限制 | 2.0 表现 | 2.5 改善 | 对策 |
|------|---------|---------|------|
| 时长衰减 | 8-12s 后质量下降，15s 末段纹理崩坏 | 30s 保持一致性 | 2.5 可放心用 30s；2.0 仍优先 ≤10s |
| 复杂动作 | 开门/打斗/转身易变形 | 长尾动作解锁，复杂物理交互流畅 | 2.5 可尝试复杂动作；2.0 仍用剪辑绕开 |
| 跨镜头一致 | 靠运气 | 切镜一致性显著提升 | 2.5 多镜头更可靠；2.0 仍需多次生成取最佳 |
| Motion Strength | 偏差，高值(≥6)易变形 | 仍需注意 | 从低值(2-3)开始，确认稳定再调高 |
| Negative 响应 | 不稳定，写了 no face drift 仍会 drift | 大幅优化，禁止项响应更好 | 2.5 用"禁止"表述；生成后仍需人工检查 |
| 多人 | 双胞胎/换脸错位 | 多人参考升级解决 | 2.5 多人场景用多人参考；2.0 避免多人同框 |
| 多语种 | 发音不准/不支持长素材 | 10+ 语种原生，口型字幕对齐 | 多语种必须用 2.5 |
