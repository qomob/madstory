# 创作模式详情 (Layer 1 — 按需加载)

> 本文件包含 11 种创作模式的完整说明。仅在用户确认模式后加载当前模式的详情。
> **2.5 为默认基准**，各模式的 2.5 增强点见对应「2.5 能力」小节。降级到 2.0 时这些增强不可用，规则见 `seedance_v2_rules.md`。

---

## Mode 0: 电影创意探索 (Creative Film)
- **场景**: 概念开发、风格实验、灵感发散、艺术短片、品牌概念片前期探索
- **核心能力**: 风格混搭建议、意外转场推荐、情绪反差提案、视觉隐喻生成、导演视角切换
- **Harness 机制**: 采用 **Generate-and-Filter + Tournament** 模式——先生成多个创意方向，再通过评分矩阵筛选最优方案
- **默认模式**: Text-to-Video
- **Seedream 5.0 Pro 增强**: 图片模式下可利用影视感自动增强和人像质感提升，在概念探索阶段直接生成接近最终质量的电影级静帧。使用 `cinematic portrait, shallow depth of field` 等修饰词激活
- **关键护栏**: `no generic composition, no cliché visual language, no random style mixing, no emotional disconnect, no flat narrative, no derivative imagery`
- **工作流**:
  1. **Perception (感知)**: 解析用户模糊意图，提取情绪关键词和参考意象
  2. **Planning (规划)**: 并行生成 3-5 个创意方向（不同导演风格/时代/流派）
  3. **Action (执行)**: 对每个方向生成分镜草案
  4. **Feedback (反思)**: Tournament 两两比较 → 选出 Top 方案 → 迭代优化
- **质量指标**: 创意独特性、视觉一致性、情感传达力
- **Tournament 评分 Rubric**（每维度 1-10 分，总分加权计算）:

  | 维度 | 权重 | 1-3 分 | 4-6 分 | 7-10 分 |
  |------|:----:|--------|--------|---------|
  | **创意独特性** | 40% | 常见视觉套路（赛博朋克街景、雨夜霓虹等模板化意象） | 有个人选择但仍在舒适区 | 非预期但精确的视觉决策——让人记住的具体画面 |
  | **视觉一致性** | 30% | 风格元素互相矛盾（混搭不融合） | 风格统一但缺乏层次 | 每个视觉元素互相强化，形成统一的视觉世界 |
  | **情感传达力** | 30% | 情绪模糊或断裂 | 情绪清晰但单薄 | 情绪有层次转变（非单一情绪贯穿） |

  **评分规则:**
  - 总分 = 创意独特性×0.4 + 视觉一致性×0.3 + 情感传达力×0.3
  - **安全方案惩罚**: 如果某方向仅因为"不容易出错"而得分高，创意独特性上限锁定 5 分
  - **防同质化规则**: 如果两个方向得分差距 < 1.0，优先选创意独特性更高的方向
  - 评分必须标注每个维度的具体依据（哪个画面元素导致了这个分数），禁止只给分不给理由

### 2.5 能力增强
- **30s 长镜头探索**：2.5 默认 30s，概念片可一口气生成完整情绪段落，无需 15s 拆分拼接
- **多语种概念片**：直接用母语写 prompt 和台词，口型字幕逐语言对齐（10+ 语种）
- **时间戳精准导戏**：在概念探索阶段用 `[0-10s]` 时间戳控制情绪递进，避免 AI 自由发挥导致节奏失控
- **音色参考**：上传参考音频锁定旁白音色，让概念片的声画气质统一

## Mode 1: 电商产品 (Ecommerce)
- **场景**: 商品详情页视频、主图动效、PDP 循环、付费社交素材
- **核心要求**: 产品几何不变形、标签可读、镜头运动克制
- **默认模式**: Image-to-Video
- **Seedream 5.0 Pro 增强**: 支持坐标级精准编辑（框选产品局部修改材质/颜色）；PNG 透明背景输出直接用于电商主图；高密度信息呈现适合复杂产品参数图
- **关键护栏**: `no label blur, no packaging warp, no logo distortion, no duplicate product`
- **镜头策略**: 单动作、单机位、产品占画幅 > 40%

### 2.5 能力增强
- **白模细颗粒度渲染**：上传 Maya/Blender 白模，用细颗粒度公式将白模动画渲染为最终成片，材质/光影/风格一键替换（见 `seedance_25_rules.md` §2.7）
- **局部编辑换色号/包装**：用智能编辑公式 `在视频的 X-Ys，把产品的[颜色]替换为[新色号]`，精准修改产品色号或包装，不影响其他元素
- **30s 完整展示**：前 10s 外观 → 中间 10s 功能 → 最后 10s 效果，用时间戳控制分阶段展示（见 §3.3）

## Mode 2: UGC 原生广告 (UGC)
- **场景**: 信息流投放素材、创作者口播、种草测评
- **核心要求**: 面部一致、手势自然、节奏"社交感"、产品不消失
- **默认模式**: Reference-to-Video
- **Seedream 5.0 Pro 增强**: 人像质感提升（毛孔级皮肤纹理+自然眼神光）让 UGC 创作者形象更真实可信；多轮对话式编辑可逐步精修（先换背景→再改服装→再调光影）
- **关键护栏**: `no face drift, no extra fingers, no lip mismatch, no product disappearance, no shaky framing`
- **镜头策略**: 单人、单信息点、保留原生感（不要过度电影化）

### 2.5 能力增强
- **音色参考 + 多语种口播**：上传创作者音色音频 `参考@音频1说XX，并保持[语调]`，高保真复刻音色；多语种版本直接用母语写台词，口型字幕逐语言对齐（见 §4.3/4.5）
- **BGM 分离提纯**：用 `去除背景音乐，保留清晰的人声` 分离已有素材的 BGM，保留口播人声
- **去字幕 BGM 生成**：2.5 有效解决随机字幕和无关 BGM 意外出现的问题，`纯净视频，无字幕，无背景音乐`

## Mode 3: 电影感品牌短片 (Cinematic)
- **场景**: 品牌故事片、发布预告、创意前贴
- **核心要求**: 明确的镜头意图、精心设计的灯光逻辑、单个情绪 payoff
- **默认模式**: Text-to-Video 或 Image-to-Video
- **关键护栏**: `no shaky camera, no object melting, no random text, no flat blacks`
- **镜头策略**: 每个镜头只做一件事。多镜头通过序列编排实现复杂叙事。

### 2.5 能力增强
- **30s 长视频 3 模块公式**：品牌短片可一口气生成 30s 完整叙事，无需 15s 拆分。使用「总述 + 多模态参考层 + 全局设定 + 时间戳剧本分镜」3 模块公式（见 §2.3）
- **时间戳精准导戏**：用 `[0-10s] [10-20s] [20-30s]` 时间戳控制情绪递进，每个时间切片含景别+构图+动作+情感潜台词（见 §3.2）
- **真人 7 维人物公式**：品牌主角用 7 维公式描写 + "保留微细毛孔与肌肤纹理"保真后缀，去 AI 感（见 §2.2）

## Mode 4: 多镜头叙事 (Multi-shot)
- **场景**: 完整叙事弧线、产品使用场景、品牌故事
- **核心要求**: 角色/产品跨镜头一致、过渡自然、节奏把控
- **默认模式**: Reference-to-Video + Multi-shot syntax
- **关键护栏**: 每个镜头 2-3 个分段，使用 `Cut to` / `Camera cut to` / `Shot Switch`
- **镜头策略**: 1 次生成 = 2-3 个镜头，总时长 ≤ 15s；更长叙事通过多次生成 + 后期拼接
- **剪辑理论应用**（在 Phase 2 时间轴规划时决策）:
  - **景别递进**: Establishing wide → medium action → close-up emotion（经典递进）；或反向使用特写开场制造悬念后拉远揭示
  - **180度线**: 多镜头对话场景中所有机位保持在对话轴线同一侧
  - **镜头时长分配**: 情绪镜头 3-5s（让观众读完表情）；动作镜头 1-2s（保持节奏感）；建立镜头 3-4s（让观众定位空间）
  - **转场意图**: `Cut to`=硬切/快节奏/戏剧揭示；`Camera cut to`=机位切换/采访风格；`Shot Switch`=场景转换+视觉桥接

### 2.5 能力增强
- **超长视频 180s**：超长模式单次直出 30-180s，完整叙事弧线无需多次生成拼接。使用超长公式（全局参数+素材描述+一句话概述+具体情节+全局补充，见 §2.4）
- **视频延长套娃 60s**：原视频 ≤30s 可延长，单次延长 4-30s，套娃式最长 60s。一镜到底延长用自然连贯公式，切镜延长用转场公式（见 §2.5）
- **无缝转场**：两段视频自动生成补全间隙，保持原视频不被修改。`将@视频1和@视频2无缝衔接，不修改原视频，[转场描述]`（见 §5 能力 15）
- **时间戳多镜头剧本**：用 `[0-10s] [10-20s] [20-30s]` 时间戳精确控制每个镜头停留时长，避免剧情"快进"（见 §3）

## Mode 5: 一镜到底 (One-Shot Long Take)
- **场景**: 产品体验流程、空间巡游、品牌沉浸式展示、创意转场视频
- **核心要求**: 2-10 张图片输入 → AI 自动补足转场画面 → 连贯长镜头输出
- **输入类型**: 图片序列（2-10 张）
- **关键能力**: 空间连续性、运镜流畅性、节奏合理性
- **转场设置**:
  - 自定义转场描述（推/拉/螺旋/溶解/匹配剪辑等）
  - 仅设转场时长（AI 自动发挥）
  - 支持逐段落描述转场方式
- **关键护栏**: `no abrupt cuts, no spatial discontinuity, no object mutation between frames, no stutter in transitions`
- **质量指标**: 镜头空间连续、运镜流畅、转场自然不跳帧

### 2.5 能力增强
- **30s 长一镜到底**：2.5 默认 30s，空间巡游可完整展示，无需 15s 限制。最长可用视频延长套娃至 60s
- **多宫格分镜参考**：上传线稿/火柴人分镜图作为剧情参考，先介绍分镜指代 → 主体设定 → 逐镜补齐构图/景别/运镜/动作（见 §5 能力 16）
- **时间戳控制长一镜**：30s 长一镜用 `[0-10s] [10-20s] [20-30s]` 时间戳控制不同空间段落

## Mode 6: 爆款复刻 (Viral Replicate)
- **场景**: 灵感来源、竞品素材翻拍、爆款模板复用、经典影视猫化/狗化
- **核心要求**: 一键复制心动视频的文案结构、剧情框架、配乐画风
- **输入类型**: 参考视频（必选）+ 替换主体参考图（可选）
- **复刻策略**:
  - **创意拍摄复刻**: 复用参考视频运镜方式和创作手法，替换主体
  - **经典影视还原**: 复刻全部细节，替换人物（如换成猫/动画角色）
  - **爆款拆解再生**: 解析爆点原因 → 借鉴文案/主题/画面风格 → 重新创作
- **提示词模式**: `参考[@视频1]的运镜方式和创作手法，将主体更换为[@图片1]，创作成类似风格的[品类]视频`
- **关键护栏**: `no style drift from reference, no subject identity loss, no mismatched pacing`
- **质量指标**: 风格还原度、主体替换自然度、节奏匹配度

### 2.5 能力增强
- **迁移创意**：不只复刻画面，更迁移深层情绪/镜头语言/网感逻辑。`@参考视频` + 描述迁移内核（如"将悬疑紧张感迁移为可爱喜剧效果"，见 §5 能力 8）
- **绿幕编辑**：上传绿幕视频 + `将背景替换为[中世纪魔法森林，光影神秘]`，高精细分割+动态场景（见 §5 能力 13）
- **BGM 分离**：复刻时先分离原视频 BGM（`去除背景音乐，保留人声`），再单独处理音轨

## Mode 7: Agent 模式 (Agent Mode — 从一句话到成片)
- **场景**: 零基础创作者、有脚本需组织、有素材需整合、跨风格创作
- **核心要求**: 输入一句话 / 脚本 / 素材 → Agent 自动理解意图 → 规划创作路径 → 调度最优模型 → 输出成品
- **适用人群**:
  - 零基础: 不会写分镜，从"一句话"出片
  - 有脚本: 把台词、镜头、节奏交给 Agent 组织成片
  - 有素材: 图片/视频/文案丢进去，做"从素材到成片"的组合拳
  - 追求风格: 写实电影感、3D、二次元、国风漫画等同一套流程
- **创作链路**:
  1. 意图解析: 抽取主体、风格、时长、情绪
  2. 路径规划: 选择最优创作模式（Text-to-Video / Image-to-Video / Reference-to-Video / Multi-shot）
  3. 分镜编排: 自动生成分镜头脚本
  4. 模型调度: 推荐 Seedance 2.5 参数组合（默认）；积分敏感时降级 2.0
  5. 提示词合成: 逐镜头输出完整提示词
- **关键护栏**: 按最终选定子模式注入对应 Negative Prompt
- **质量指标**: 意图理解准确度、分镜完整性、风格一致性

### 2.5 能力增强（路由决策）
- **超长视频路由**：意图含"完整故事/长叙事"时路由到超长视频模式（30-180s），使用超长公式
- **智能编辑路由**：意图含"修改已有视频/换色/换背景/去元素"时路由到智能编辑模式
- **白模路由**：意图含"3D/白模/Maya/Blender/预演"时路由到白模模式
- **多语种出海路由**：意图含"多语种/出海/本土化/多语言"时启用多语种能力，用母语写 prompt
- **视频延长路由**：意图含"延长/续拍/加长"时路由到视频延长（套娃 ≤60s）

## Mode 8: 短剧创作 (Short Drama)
- **场景**: AI 短剧全自动生产、漫剧创作、小说改编短剧
- **Seedream 5.0 Pro 增强**: 多轮对话式编辑非常适合短剧角色卡迭代（同一角色不同场景/服装/表情）；人像质感提升让角色立绘达到商业级；多语种文字渲染支持国际化字幕
- **工作流关系（重要）**: Mode 8 采用 **Stage A-H 为主线**，Phase 0-7 作为每段戏份的镜头级推导子流程嵌入其中。具体映射：
  - Stage E（剧本设计）→ 产出每集的镜头清单
  - Stage F（角色卡）→ 为 Phase 1（核心创意锁定）提供角色外观输入
  - Stage G（分镜切割）→ **每段戏份进入 Phase 0-7 推导**（Phase 0=确认该段 Mode 8 上下文 → Phase 1-7=该镜头的全参数推导）
  - Stage H（提示词生成）→ Phase 7 输出的最终提示词汇集
  - Stage A-D（一致性管控）→ 贯穿全程，在 Phase 7 质量自检时执行校验
- **核心能力**:
  - 剧本全自动解析 → 连贯生成完整剧集
  - 全局角色/场景管理 → 角色不同时空妆造精准映射
  - Agent 智能旁白改编
  - 多画风支持（写实/漫画/3D/二次元）
  - 多剧集连发
- **输入格式**: 标准剧本（含场景标注、人物标注、对白/OS/动作描述）
- **角色一致性**: 在分镜故事板中 @角色形象 保持跨镜头一致
- **关键护栏**: `no character face drift across episodes, no costume inconsistency, no scene discontinuity, no voice mismatch`
- **质量指标**: 角色跨集一致性、剧本还原度、旁白自然度

### 2.5 能力增强
- **多人参考**：解决多人场景"双胞胎（长相趋同）"与"换脸错位"问题。每个角色独立面部轮廓、五官、专属气质、专属穿搭，提示词明确各角色动作与关系（见 §4.4）
- **音色参考**：为每个角色绑定专属音色，`上传目标音色音频 + 文案 + 参考@音频1说XX，并保持[语调]`，高保真音色复刻 + 情感细节（见 §4.3）
- **多语种出海**：直接用母语写 prompt 和台词，口型字幕逐语言对齐（10+ 语种）。强制语言输出 `最终成片中的所有文字必须全部为[韩文]，禁止出现中文、英文或其他语言`（见 §4.5）
- **跨集延长**：单集 ≤30s 可延长，套娃 ≤60s；超长模式 30-180s 可生成完整长集
- **30s 3 模块公式**：每段戏份用「多模态参考层 + 全局设定 + 时间戳剧本分镜」3 模块公式，角色站位锁定 + 防崩坏禁止项（见 §2.3）

## Mode 9: 智能编辑 (Smart Edit)
- **场景**: 局部消除、局部替换、空间视角修改、BGM 分离、去字幕、绿幕合成
- **核心要求**: 精准定位防误伤、保留不变要素声明、移除后自然补全
- **默认模式**: 智能编辑（即梦界面 4 选 1 之一，2.5 新增）
- **输入类型**: 已生成视频 / 本地上传视频
- **关键能力**: 局部无痕消除、定向元素替换、机位视角重构、音轨分离
- **编辑公式**（见 `seedance_25_rules.md` §2.6）:
  - **智能编辑**（文字描述）：`[具体修改对象] + [动作与变化描述] + [生效时序]`
    - 必填词：编辑视频里的 xx / 增加 / 删除 / 修改 / 替换 / 改成
    - 尽可能写 A → B 的变化
    - 例：`在视频的 1-8 秒，把男生的牛仔裤，替换为深黑色的西装裤`
  - **高级编辑 / 视频编辑**（圈选标记 + 文字）：`[标注工具与方位] + [具体修改对象] + [动作与变化描述] + [生效时序]`
    - 标注工具：框/线/箭头/文字/地标点 + 关注内部还是外部（如"红框内""沿着红色箭头指向的区域"）
    - 生效时序：全片统一修改 / 仅在 X-Ys 期间变化 / 从第 N 秒起逐渐显现
- **保留不变要素声明**（强制，缺则质量门禁不合格）:
  - `保持其他不变`、`人物本人、皮肤、头部、手脚、身体姿态、运动动作保持不变`
  - 移除后补全：`原本被遮挡的[地毯/墙面]需要自然补全，不能留下残影或模糊补丁`
- **专项能力**:
  - **局部消除**：智能无痕消除画面中的元素（如消除路人、水印、杂物）
  - **局部替换**：定向替换元素（换服装色号、换背景、换道具）
  - **空间视角修改**：机位视角重构 + 外推补全。`将平视镜头修改为从高空俯拍，镜头缓慢向下推进`
  - **BGM 分离**：`去除背景音乐，保留清晰的人声`（去 BGM 留人声/环境音，保留字幕）
  - **去字幕 BGM**：`纯净视频，无字幕，无背景音乐`
  - **绿幕编辑**：上传绿幕视频 + `将背景替换为[目标场景描述]`，高精细分割 + 动态场景
- **关键护栏**: `no unintended modification of preserved elements, no residual artifacts, no incomplete inpainting`
- **质量指标**: 修改精准度、不变要素保留度、补全自然度
- **质量门禁专项**: 未声明保留的不变要素 → 不合格

## Mode 10: 白模预演 (White Model Preview)
- **场景**: Maya/Blender 白模渲染、3D 分镜预演、镜头/空间/走位精准控制
- **核心要求**: 白模与渲染主体对应关系映射清晰、镜头/空间/走位精准
- **默认模式**: 白模控制（Maya/Blender 插件，2.5 新增）
- **输入类型**: 视频（白模动画）+ Image（角色/场景参考图）
- **两种颗粒度**:
  - **粗颗粒度**（简单几何体，提供动态骨架，从零生成全新视频）:
    ```
    【参考声明】+【对应关系映射】+【剧情详述】+【场景处理】+【整体收束】
    ```
    - **参考声明**：参考[视频1]的 {运镜|动作|动线|光影变化|角色站位|音乐音效|画面节奏}
    - **对应关系映射**：将[视频1]中的 {颜色/形状特征} 模型替换为[图X]的 {角色名}
    - **补充**：粗颗粒度若有四肢/翅膀，需写出完整动作序列避免僵化。**最佳实践：不上传有四肢/翅膀类的模型**
  - **细颗粒度**（建模完整，材质/光影/风格替换）:
    ```
    【渲染指令】+【分段渲染描述】+【场景处理】+【整体收束】
    ```
    - **渲染指令**：将[视频1]的白模动画渲染成最终成片
    - **分段渲染描述**：`0-{N}s：{渲染要求——背景环境、色调氛围、人物材质、光影效果} {N}s {转场触发点与方式}：{转场后新场景渲染描述}`
    - **补充**：上传参考视频需去除 {轨迹线|坐标线|相机 cone} 等干扰信息
- **关键护栏**: `no rigidity in limb animation, no coordinate line artifacts, no mismatch between model and rendered subject`
- **质量指标**: 镜头/空间/走位精准度、渲染自然度、动作流畅度
- **质量门禁专项**: 白模与渲染主体对应关系映射缺失 → 不合格
